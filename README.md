# Sistema Integral de Gestión de Clientes, Servicios y Reservas

Proyecto desarrollado en Python para la empresa Software FJ como parte de la Fase 4 del curso Programación.

## Características

- Gestión de clientes.
- Gestión de servicios.
- Gestión de reservas.
- Programación Orientada a Objetos.
- Herencia, polimorfismo y abstracción.
- Manejo de excepciones.
- Registro de errores mediante logs.
- Simulación de operaciones válidas e inválidas.

## Tecnologías utilizadas

- Python 3
- Programación Orientada a Objetos
- Logging
